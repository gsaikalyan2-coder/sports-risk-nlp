### Key decisions

- **Secret-scan hook = `detect-secrets`** (owner-confirmed this session). Pure Python, pip-installable,
  no platform binary to manage on Windows - unlike gitleaks.
- **Pinning = manifest + lock**, not hand-edited `==` pins. `requirements.txt` stays human-readable;
  `pip freeze > requirements.lock.txt` produces the exact reproducible set. Guessing pins without a
  real resolver run would have been fake reproducibility.
- **Torch: CPU-only wheel** documented as the default path; GPU fine-tuning (Phase 14) goes to Colab.
