# apt packages installed by the Hugging Face Space before requirements.txt.
#
# The OCR engine for the photo path (src/media/extract.py). Two packages, not
# one: tesseract-ocr is the binary, tesseract-ocr-eng is the English language
# data, and the engine without the language data fails at the point of use with
# a message about a missing file path.
#
# Their absence is a SILENT feature loss, not a crash. The extractor checks
# whether the engine runs, finds it does not, and selects the honest floor -- so
# the Space starts, the uploader appears, and every photo is refused with "this
# build cannot read photos". Correct, and indistinguishable from broken.
#
# Not listed here, deliberately: a speech model for the video path.
# faster-whisper pulls a multi-hundred-megabyte runtime and downloads weights on
# first use, which a free Space cannot carry. The video path therefore refuses
# honestly in deployment, and says which package is missing.
tesseract-ocr
tesseract-ocr-eng
