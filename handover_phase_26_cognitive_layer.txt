THE ARCHITECTURAL FINDING THAT MAKES THIS PHASE CHEAP
--------------------------------------------------------------------------------
src/risk/fusion.py has carried an unused integration seam since Phase 15:
LinearRiskScorer.score() accepts a `context` mapping and ignores it unless
`context_weights` were configured, and RiskScore propagates `context_used` into
the explanation. The docstring records the intent: "the text-only path is not
merely the default; it is a separate, tested code path, so adding context cannot
silently change the index."

Phase 26 fills that slot at weight zero. The existing test proving the text-only
path is numerically identical becomes the regression guard for the whole layer.

BLOCKING GATE - READ BEFORE WRITING ANY CODE
--------------------------------------------------------------------------------
Nothing in Phase 26 touches a human being. The moment that changes - including
the owner recording himself - docs/ethics.md and docs/model_card.md must be
updated FIRST, with a consent route, a retention rule, and a statement that
physiological data is a different privacy class from synthetic text.

V5 is additionally an INTERVENTION, not an observation: a closed feedback loop
changes the behaviour of the person in it. Before V5 runs against any person it
needs ethics approval and a clinician in the loop. The plan specifies a guard in
src/biosignals/sources.py that refuses any non-simulated source until then, and
the V5 page refuses to render unless the configured source is a SimulatedSource.
